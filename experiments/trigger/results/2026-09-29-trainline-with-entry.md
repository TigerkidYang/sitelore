### sonnet-A-trainline-2

**Search results page can return a hard bot-detection block instead of results** (https://www.thetrainline.com)

_applies when:_ UK site, English (UK), not logged in, automated browser (Playwright-driven)

After submitting a one-way UK search (e.g. London to Manchester) via "Find cheap tickets", the results tab sometimes shows "No trains available" / "Something went wrong, please try again" and then a full-page "访问暂时受限" (access temporarily restricted) bot-verification block instead of the fare list, both on first load and after reloading the same results URL. This happened consistently across two attempts with automated browser control (Playwright), even with a normal desktop viewport and no obvious rapid-fire actions. There is no legitimate way to get past this within the page itself (it's an anti-bot wall, not a UI element to click through) — agents should not try to solve it, and should report to the user that live results were unavailable due to the site's bot detection rather than assuming there are no trains.
